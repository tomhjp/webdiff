# docs

**These docs are LLM-generated.** An agent wrote them together with the
code, and nobody has fully reviewed them. They can be wrong, incomplete, or
out of date. If a doc and the code do not agree, the code is correct.

- [install.md](install.md): install webdiff, and its flags.
- [sessions.md](sessions.md): agent sessions in Rex or tmux, and more than one
  agent for each checkout.
- [selecting-changes.md](selecting-changes.md): select commits on the diff
  page, the commit view, and edit commit messages.
- [worktrees.md](worktrees.md): managed worktrees.
- [editor-links.md](editor-links.md): open a checkout in Zed, VS Code, or
  Ghostty.
- [desktop-client.md](desktop-client.md): `webdiff client`, **send to github**,
  and the VS Code extension.
- [pull-requests.md](pull-requests.md): the pull request of each branch.
- [issues.md](issues.md): the GitHub issues of each branch.
- [terminal-palette.md](terminal-palette.md): match the colours of your
  terminal.
